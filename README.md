# Financial Data Analyst Agent

An AI-powered financial data analysis agent that aims to help users query and understand financial data through natural language.

## Project Overview

Financial Data Analyst Agent is a learning and portfolio project developed as part of my AI Production Engineering journey.

The long-term goal is to build an AI application that can translate natural-language financial questions into database queries, retrieve relevant data, and generate clear analytical insights for non-technical users.

## Target Users

- Financial analysts
- Business analysts
- Product managers
- Operations and management teams

## Planned Capabilities

- Natural language financial data querying
- AI-generated SQL
- SQL review and validation
- PostgreSQL database execution
- Structured result tables
- Financial insight generation
- Multi-Agent workflow
- Evaluation and monitoring

## Planned Tech Stack

- Python
- FastAPI
- PostgreSQL
- Docker
- Docker Compose
- LangGraph
- Large Language Models
